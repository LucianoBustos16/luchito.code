# luchito.code

Editor en vivo de HTML, CSS y JavaScript en el navegador, estilo CodePen.

## Características

- Editor Monaco (el de VS Code) con Emmet para HTML
- Vista previa en tiempo real
- El código se guarda en la URL: copiá el link y compartilo
- Paneles redimensionables
- Configuración del editor (tema, fuente, minimapa, etc.) guardada en el navegador
- Atajo `Ctrl + ,` para abrir la configuración

## Uso

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev`: servidor de desarrollo
- `npm run build`: build de producción
- `npm run preview`: previsualiza el build
- `npm run lint`: revisa el código con standard
